# 外贸工作台 V6.1 Free 稳定版

这版是在你 2026-09-05 的 V6 AI 智能开发闭环版上做的“稳定性补丁”，不改变现有业务模块。

## 你现在需要做的

1. **不要删除当前浏览器里的旧工作台数据。**
2. 新建一个 Supabase Free 项目。
3. 在新项目 SQL Editor 执行：`SUPABASE_FREE_V61_初始化.sql`。
4. 把本目录文件部署到原 GitHub Pages 仓库。
5. 打开工作台 → 设置 → 填新的 Project URL + publishable key → 连接。
6. 确认顶部显示“☁️ 云端在线”后，再点“上传到云端”。
7. 在手机端用同一 URL + key 连接并核对数据。
8. 如需最大限度避免 Free 项目因低活跃暂停，按 `V6.1_Supabase_Free稳定版接入指南.md` 配置 GitHub Actions 保活。

## 本版关键修复

- 页面打开后自动恢复 Supabase 连接，不再每次刷新都退回纯本地模式。
- 云端异常时保留本地数据，不把网络错误当成“空库”。
- 上传/拉取前保留最近一份本地安全快照。
- 设置页增加“健康检查”和“恢复安全快照”。
- 顶部增加“云端在线 / 云端异常 / 本地模式”状态灯。
- `aiHistory`、`marketAnalyses` 改为安全合并，不再直接被云端空表覆盖。
- JSON 追加导入同时可增量合并 To-do。
- 首次启动自动清理旧版本造成的 notes 单字符污染。
- Supabase 轮询从 12 秒调整为 30 秒，减少无意义请求。
- 附带 GitHub Actions 免费保活工作流和新的初始化 SQL。
- 已从部署文档中移除旧 Supabase 项目 URL / key。

## 重要：业务数据文件单独保存

本工作台 ZIP **不包含你的客户 JSON**，避免你把 ZIP 上传到公开 GitHub Pages 后意外公开客户资料。

你的 `外贸工作台数据_2026-09-19_V6.1修复版.json` 请只保存在本地，用工作台“导入 JSON（新增）”导入。
